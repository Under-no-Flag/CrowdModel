# 中文期刊实验章节写作

## 核心目标

将实验章节写成“研究问题、实验设置、对比方法、结果、分析、结论”的论文叙述，而不是“做了什么、跑了哪些实验、结果文件在哪里”的过程记录。保留所有可核查数据，不凭空增加结论。

## 改写流程

1. 先识别章节中的研究目的、实验对象、控制变量、评价指标、对比方法、消融因素和主要结论。
2. 删除或弱化工程过程痕迹，包括代码路径、实验批次名、运行日志、文件来源、调试背景、时间顺序口吻和“当前/本轮/需要注意”等记录式表达。
3. 按论文逻辑组织内容：实验设置先给出统一场景与评价指标，机制验证说明模型有效性，响应实验说明变量可优化性，对比实验说明方法有效性，消融实验说明设计必要性。
4. 对每个结果段采用“实验目的 -> 数据结果 -> 机理解释 -> 结论边界”的顺序。
5. 用审慎语言表达结论。若存在失败种子、非单调权衡或方法不稳定，明确写成局限或后续改进方向，避免绝对化表述。

## 文体规则

- 使用第三人称或“本文”作为主语，避免“我/我们/本周/这次/先/然后/跑一遍”等口语和过程词。
- 表达应客观、克制、连续，少用编号式流水账。列表和表格用于承载信息，正文用于解释逻辑。
- 保留数学符号、公式、图号、表号、指标数值和方法名称。
- 不在正文中暴露代码文件、结果目录、CSV 文件名、seed 调试说明，除非它们本身是复现实验设置的一部分。
- 不把低保真或中保真结果写成最终最优依据。最终性能结论只依据统一高保真复验。
- 对“最优”类表述加限定条件，如“在相同预算与五个随机种子的设置下”。

## 实验章节常用句式

- “为检验……，本文设置……”
- “结果表明，……，说明……”
- “与……相比，……，表明该设计在……方面具有优势。”
- “该现象说明……之间存在权衡，因此需要联合优化。”
- “需要指出的是，……，因此本文将其作为后续改进方向，而不将其表述为普遍占优。”

## 输出检查

交付前检查以下问题：

- 是否还保留明显的实验报告口吻。
- 是否存在未解释的实验编号、代码目录或文件名。
- 表格和图像是否都被正文解释。
- 结论是否由表格中的高保真结果支撑。
- 是否准确区分主实验、基线对比、消融和机制验证。
